## About

<div align="center">
  <img src="./assets/images/about.svg?v=3" alt="About Alok Prasad — Core Engineering Approach and Architectural Focus" width="100%" />
</div>

<br />

I’m **Alok Prasad**, pursuing **B.Tech** in **Computer Science Engineering** (Batch 2023–2027) from **Rungta College of Engineering** (now Rungta International Skills University) in Bhilai, India, focused on building practical software systems that combine thoughtful engineering, modern web technologies, and applied artificial intelligence.

My work focuses on three engineering areas:

- **Privacy-first client-side AI and computer vision**: running inference in the browser with MediaPipe, ONNX Runtime Web, and TensorFlow.js so sensitive biometric or camera data never leaves client memory (`Haziri.AI`, `GymGenie`, `SolarGuard`, `TalentPulse`).
- **Resilient backend and security engineering**: designing PostgreSQL Row Level Security boundaries, SSRF socket IP pinning, transactional outbox alerting, rate-limiting mitigation pipelines, and hardware-backed cryptographic unlock flows (`SENTRIX`, `PulseWatch`, `CivicTrack`, `KeyLink`).
- **Full-stack product engineering and applied ML**: taking systems from schema design and typed API contracts through testing, containerization, and deployment across TypeScript, React/Next.js, Python/FastAPI, Express.js, and PyTorch/scikit-learn.

Currently deepening production skills in **AWS infrastructure, distributed queues (`Redis` / `BullMQ`), Dockerized services, and automated CI/CD verification**.
