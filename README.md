## Featured Projects

### Featured · 01 — Haziri.AI
**AI-Powered Attendance & Identity Platform**

<img src="./assets/project-previews/haziri.png?v=1" alt="Haziri.AI application interface showing biometric attendance workflows" width="480" />

A privacy-first classroom attendance and biometric identity system. Face detection, 478-point landmark alignment, and 128D OpenCV SFace embedding extraction run in the browser through WebAssembly and ONNX Runtime Web. Raw classroom photos remain in client memory and are not uploaded to servers.

**Core engineering:**
- **Browser-side biometric pipeline:** MediaPipe face detection, 5-point affine alignment to 112x112, and L2-normalized SFace 128D cosine matching (threshold >= 0.363), with multi-photo deduplication and source attribution.
- **Passwordless FaceID authentication boundary:** Student 128D vectors are verified inside a least-privilege PostgreSQL RPC (`verify_student_face_for_otp`) before issuing Supabase Auth sign-in links or six-digit OTPs. No `SUPABASE_SERVICE_ROLE_KEY` exposure.
- **Tenant isolation and idempotency:** Row Level Security across seven PostgreSQL tables, UUID idempotency keys for attendance writes (`save_attendance_session`), and teacher review overrides.

**Portals and architecture:**
- **Teacher portal:** Course creation, downloadable QR enrollment links, batch attendance matching across multiple photos, manual verification overrides, CSV exports, and cascading subject deletion through `delete_teacher_subject`.
- **Student portal:** Password or FaceID OTP sign-in, consent-tracked biometric enrollment, QR deep-link joining (`/?join-class=CODE`), and per-subject attendance history.
- Monochrome spatial glass UI with a Three.js / React Three Fiber 478-point landmark mesh; strict TypeScript.

- **Inference:** On-device WASM / ONNX Runtime Web; no server-side image uploads.
- **Security:** Seven-table PostgreSQL RLS, narrow RPCs, and Zod request guards.
- **Testing:** Vitest security boundaries, Playwright E2E, and SQL RLS checks.
- **Technology stack:** Next.js 16, React 19, TypeScript, Tailwind CSS v4, Three.js, Framer Motion, MediaPipe, ONNX Runtime Web, Supabase, PostgreSQL, Zod, Vitest, Playwright.
- **Source:** [https://github.com/alokprasad573/Haziri.AI](https://github.com/alokprasad573/Haziri.AI)
- **Live demo:** [https://haziriai.vercel.app/](https://haziriai.vercel.app/)

### Featured · 05 — SENTRIX
**Autonomous DDoS Detection, Monitoring & Defense Simulator**

<img src="./assets/project-previews/sentrix.png?v=1" alt="SENTRIX SOC dashboard showing traffic telemetry and DDoS mitigation status" width="480" />

An autonomous cybersecurity platform and cyber range simulator built to detect volumetric and behavioral L7 attacks in real time, stage safe dry-run mitigations, and distinguish flash crowds from malicious floods.

**Core engineering:**
- **ML + heuristic detection engine:** Combines a scikit-learn `ColumnTransformer` preprocessing pipeline and regularized `RandomForestClassifier` (`rf-1.0.0`, 99.675% held-out test accuracy, 99.68% recall, 0.9995 ROC-AUC, 19.26 ms P95 latency; 95.58% synthetic benchmark) with EWMA velocity Z-scores.
- **Flash crowd vs. attack differentiation:** Evaluates Shannon entropy (>= 0.75) across behavioral traffic signals before escalating alerts or staging leaky-bucket rate limits.
- **Simulation and telemetry exporters:** Includes an M/M/1 discrete-event cyber range simulator and NGINX / Caddy reverse-proxy log exporters.

**Architecture and verification:**
- Asynchronous FastAPI backend with Uvicorn, SQLAlchemy 2.0 ORM, Alembic migrations, and PostgreSQL (SQLite fallback for local development), paired with a Next.js 16.4 / React 19.3 / Tailwind CSS v4 / Recharts SOC dashboard.
- **Security:** Dry-run mitigation guardrails preventing accidental self-lockouts and structured audit logs.
- **Testing:** 173 pytest test cases plus Ruff linting and Docker/Render deployment configurations.
- **Technology stack:** Python, FastAPI, Uvicorn, scikit-learn, NumPy, Pandas, SQLAlchemy, Alembic, PostgreSQL, Next.js 16, React 19, TypeScript, Tailwind CSS v4, Recharts, NGINX, Caddy, Docker, Render, pytest.

### Featured · 06 — PulseWatch
**API Monitoring & Incident Management Platform**

<img src="./assets/project-previews/pulsewatch.png?v=1" alt="PulseWatch dashboard tracking API uptime, latency percentiles, and incidents" width="480" />

A distributed synthetic API monitoring and incident management platform engineered as a Turborepo TypeScript monorepo with SSRF-hardened workers, sub-millisecond timing, and reliable alert delivery.

**Core engineering:**
- **SSRF-hardened probe execution:** Pre-resolves DNS records in `services/worker/src/ssrf.ts` and pins validated public IPs directly at socket connection time to prevent DNS rebinding and private-network SSRF.
- **Noise-resistant outage detection:** Uses `process.hrtime.bigint()` for probe latency timing and a 3-strike hysteresis state machine (`UP` / `DEGRADED` / `DOWN`) before opening incidents.
- **Transactional outbox alerts:** Persists incident transitions alongside outbox records so Slack Block Kit notifications survive transient worker failures.

**Architecture and verification:**
- Monorepo workspaces separating `frontend` (Next.js 14.2, React 18, Tailwind CSS, Recharts), `backend` (Express 4.21 MVC API with Argon2 password hashing and JWT refresh rotation), `services/scheduler`, `services/worker` (Redis + BullMQ), and `packages/database` (PostgreSQL + Prisma).
- **Testing:** 36-test system verification harness covering API endpoints, SSRF guards, and worker lifecycles; multi-stage Dockerfiles and Render blueprint.
- **Technology stack:** TypeScript, Turborepo, Next.js 14, React 18, Tailwind CSS, Recharts, Express.js, Prisma, PostgreSQL, Redis, BullMQ, Argon2, Docker, Render.
- **Source:** [https://github.com/alokprasad573/PulseWatch](https://github.com/alokprasad573/PulseWatch)
- **Live demo:** [https://pulse-watch-eta.vercel.app](https://pulse-watch-eta.vercel.app)

### Featured · 07 — SolarGuard
**Solar Panel Anomaly Detection**

<img src="./assets/project-previews/solarguard.png?v=1" alt="SolarGuard solar panel defect classification interface running in-browser inference" width="480" />

An automated inspection web application that classifies solar module imagery across six physical and environmental conditions directly inside the browser using quantized deep learning weights.

**Core engineering:**
- **Quantized Float16 TensorFlow.js inference:** Executes a 12.12 MB (3-shard) `EfficientNetV2B0` GraphModel directly in client JavaScript without uploading inspection photos to an inference server.
- **Evaluated 6-class diagnostics:** Distinguishes `Bird-drop`, `Clean`, `Dusty`, `Electrical-damage`, `Physical-Damage`, and `Snow-Covered`, achieving 82.76% held-out test accuracy (82.98% 4x TTA Macro-F1 across 776 MD5-deduplicated images).

**Infrastructure and testing:**
- Built with Next.js 15.3, React 19.0, Tailwind CSS v3, a three-stage `node:22-alpine` Dockerfile, and automated `node --test` suites.
- **Technology stack:** Next.js 15, React 19, JavaScript, Tailwind CSS, TensorFlow.js (`@tensorflow/tfjs` Float16 EfficientNetV2B0), Docker, Node Test Runner.

### Featured · 08 — TalentPulse
**Employee Attrition Prediction & Proactive Retention Engine**

<img src="./assets/project-previews/talentpulse.png?v=1" alt="TalentPulse attrition risk scoring and retention driver dashboard" width="480" />

An end-to-end machine learning system that trains an ensemble turnover predictor offline in Python and distills it into an ultra-compact browser model for instant retention diagnostics.

**Core engineering:**
- **Offline ensemble pipeline:** Engineers 80 domain features from 1,470 IBM HR records with Yeo-Johnson `PowerTransformer` scaling and a 10-fold out-of-fold Stacking Ensemble (Logistic Regression, Random Forest, XGBoost, Extra Trees, Gradient Boosting, and SVC), reaching 0.8345 holdout ROC-AUC and 0.0986 Brier score.
- **Distilled edge execution:** Exports the trained estimator into a ~130 KB TensorFlow.js artifact capable of under-5 ms browser inference with zero backend latency.

**Frontend architecture:**
- Built in TypeScript with React 19, Vite 8, Tailwind CSS v4, Framer Motion, GSAP, and Recharts interactive feature-driver breakdowns.
- **Technology stack:** Python, scikit-learn, XGBoost, Pandas, NumPy, TensorFlow.js, React 19, TypeScript, Vite, Tailwind CSS v4, Framer Motion, GSAP, Recharts, Vercel.
- **Source:** [https://github.com/alokprasad573/TalentPulse](https://github.com/alokprasad573/TalentPulse)
